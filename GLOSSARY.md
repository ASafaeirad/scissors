# Scissors

Scissors combines imported media into an editable project.

## Language

**Project**:
The composition being edited, including its media library, timeline, and output settings.

**Library**:
The project's collection of imported media sources. Importing a source does not place it on the timeline.
_Avoid_: Project queue

**Source**:
An imported video, audio file, or image that can be reused in the project.

**Clip**:
An independently editable instance of a source on the timeline, with its own position, trim, and properties.

**Track**:
A timeline lane containing a clip. Selecting a track selects that clip's properties.

**Export queue**:
Conversion jobs waiting to run or currently running.
